DATA & BACKUP

Settings

Local profile

Used when you are signed out. When signed in, your Cloud Sync display name identifies every new game automatically.

Backups

JSON backup preserves every saved game and can be imported later. CSV is convenient for spreadsheets.

Scoreboard photos are not included in backups because this version does not save photos after the game is entered.

Reset

Deletes all bowling history in the currently active local profile. When signed in, those deletions also sync to that cloud account.
