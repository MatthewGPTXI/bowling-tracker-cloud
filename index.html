CLOUD SYNC

Account & leaderboards

Firebase connection needed

This build is cloud-ready, but it still needs the Firebase configuration from your own free project. Paste that configuration into firebase-config.js, then upload the updated files to GitHub.

The Firebase web configuration is designed to live in client code. Access to your bowling data is controlled by Authentication and Firestore Security Rules.
